# read-rs-paper：论文阅读与复习 Skill

面向遥感、计算机视觉和人工智能论文的个人阅读流程。支持自主通读后的逐节精读、直接全文分析、论文语境中的英语学习，以及用于 Zotero Better Notes 的复习卡。

它将阅读习惯、证据规则和笔记格式整理成可复用的 Skill，减少每次重复输入长提示词的需要。它不能保证模型每次输出完全相同；关键事实仍需结合原文核对。

## 快速开始

安装后，在 Codex 中输入：

```text
使用 $read-rs-paper 阅读我提供的这篇论文。
```

提供 PDF、可访问的本地文件，或通过可用 Zotero 插件指定论文。只提供标题且无法取得全文时，助手会说明缺失材料，不会声称已经通读。

如果没有明确选择，助手会先让你选择：

| 模式 | 适合情况 | 行为 |
| --- | --- | --- |
| A：我先自己读 | 想练习阅读、逐步理解 | 先让你自行通读，途中答疑；你说“读完了”后逐节精读 |
| B：直接通读总结 | 想先获得全文理解 | 阅读可取得的全文，输出五部分分析和复习卡；之后继续支持追问 |

也可以直接指定，省去选择：

```text
使用 $read-rs-paper，我选 A 模式，先让我自己读。
```

```text
使用 $read-rs-paper，我选 B 模式，直接通读并总结这篇论文。
```

## 安装

将本仓库内容保存到一个名为 `read-rs-paper` 的技能目录，确保 `SKILL.md` 位于该目录根部。对于使用个人技能目录的本地 Codex 环境，常用位置为：

```text
~/.codex/skills/read-rs-paper/
```

如果环境设置了 `CODEX_HOME`，以该环境的技能目录为准；不同客户端的发现路径可能有所不同。安装后打开新会话，使用 `$read-rs-paper` 调用；暂未发现时尝试重启 Codex，并检查目录和文件名。

当前仓库根目录就是 Skill 内容，安装时无需再嵌套一层同名目录。安装 Skill 不会同时安装 Zotero、Better Notes 或 Zotero 连接插件。

## 常用指令

| 想做什么 | 可以这样说 |
| --- | --- |
| 开始阅读 | 使用 `$read-rs-paper` 阅读这篇论文 |
| 进入精读 | 我读完了，开始逐节精读 |
| 继续原位置 | 继续讲下一小节 |
| 解释词句 | 解释这句话在本文中的意思，并拆解句子结构 |
| 解释机制 | 按输入、处理、输出讲清这个模块 |
| 解释公式 | 解释公式（编号），说明变量和计算顺序，必要时给最小数值示例 |
| 查看图表 | 按数据流解释图（编号），区分各条分支 |
| 分析实验 | 这个消融能支持作者的哪个结论？ |
| 生成复习卡 | 生成这篇论文的复习卡 |
| 追问后更新 | 根据刚才核对的修正，更新复习卡 |
| 恢复阅读 | 读取这篇论文的阅读记录，从上次位置继续 |

A、B 两种模式都支持单词、短语、句子、专业术语、公式、图表和研究问题的追问。回答支线后回到原阅读位置，不自动切换主题或重新总结全文。

## 阅读与解释规则

- **论文理解优先，英语学习辅助。** 普通词提供 IPA、本文含义和实用搭配；长句拆主干和修饰；技术术语优先解释机制。
- **按照真实论文结构。** 不强制所有模型都采用固定的 Backbone → Fusion → Decoder 流程。
- **Method 是重点。** 讲清模块动机、输入、逐步运算、输出、模块连接、公式和框架图；必要时提供明确标记的教学示例。
- **区分证据层级。** 原文事实、机制推导和扩展分析分别标明，不将研究启发当作作者结论。
- **区分信息缺失。** 尚未读取或无法核实写“尚未核实”；核对后确实未报告写“原文未报告”；没有相应机制写“本文不适用”。
- **谨慎解释实验。** 比较条件、指标单位和基线必须明确；论文内 SOTA 不等于当前领域最新水平；消融增益不直接证明机制因果。

B 模式的全文分析包含：核心问题与目标、方法架构与计算流程、实验与基线、批判性评价、研究启发。

## 生成 Better Notes 复习卡

最短指令：

```text
生成这篇论文的复习卡。
```

以下要求已内置，不必每次重复：

1. 基于当前原文、经核对的记录和追问修订生成。
2. 在一个可复制的 `markdown` 代码块中输出完整原始源码。
3. 行内公式使用 `$...$`，独立公式使用 `$$...$$`，保留原始 LaTeX。
4. 不混入 HTML 标签，不复制已渲染数学的内部标记。
5. 真实论文、PDF、详细笔记或相关笔记链接取得后才加入。
6. 在代码块外列出建议关联的笔记、理由、方向，并区分已存在与建议新建。

复习卡的固定字段为：论文来源、一句话记忆、核心问题、方法流程、三个关键词、关键 Loss、为什么有效、与其他方法的区别、对变化识别研究的启发、30 秒复述版、关键证据、关联知识。

B 模式全文分析后默认生成；A 模式在你要求总结或复习笔记时生成。

### 复制与公式

复制代码块**内部内容**，不要复制外层的三个反引号；默认粘贴到 Better Notes 的笔记正文。不要将普通 Markdown 粘贴到 HTML 源码编辑器或模板导入窗口。

独立公式的源码应类似下面这样（仅为格式示例，不代表当前论文真实损失）：

```markdown
## 关键 Loss

$$
\mathcal{L}_{\mathrm{perceptual}}
=
\mathcal{L}_{\mathrm{content}}
+
\eta \mathcal{L}_{\mathrm{radio}}
$$

其中，$\eta$ 是权重系数。
```

HTML 源码、普通 Markdown 和 Better Notes 模板分享代码使用不同入口。只有明确要求其他入口时，助手才应转换交付格式。

如果出现 `</span>`、`<br>` 等文字，说明标签被错误当作内容显示。可要求：

```text
请重新输出这份笔记的原始 Markdown，公式保留 $ / $$ 和 LaTeX，清除混入的 HTML 标签。
```

不同版本和粘贴入口可能影响转换。本 Skill 已进行源码及场景检查，但尚未完成用户环境中的 Better Notes 显示验证；首次使用建议检查公式保存重开后的显示。

## 与 Zotero 的关系

```text
用户指定论文 → 助手读取 Skill → 使用可用 Zotero 能力获取材料 → 阅读与答疑 → 输出笔记源码
```

Skill 是指令与资源，不自带 Zotero 连接。需要当前环境安装并提供 Zotero 插件，且本地访问可用。现有 Zotero 插件可用于查找条目、取得元数据和读取可用全文；已索引文本不一定包含可理解的图像和完整公式，需要时还应查看原 PDF。

默认由用户复制保存。**调用 Skill 不会自动创建、覆盖 Zotero 笔记，也不会自动建立 Better Notes 链接。** 自动写入需要用户明确要求以及实际可用的写入能力，不能仅凭读取插件存在就假定可以写入。

会话改名同样依赖客户端工具：可用时使用“论文简称｜核心研究主题｜会议/期刊年份”；不可用时仅给建议标题。

## 入链、出链与关系图

| 功能 | 含义 |
| --- | --- |
| 出链 | 当前笔记链接到其他笔记 |
| 入链 | 其他笔记链接到当前笔记 |
| 关系图 | 展示已建立的笔记连接 |

推荐按用途组织：

```text
研究主题 / 方法对比笔记
            ↓
       论文复习卡
       ↓       ↓
详细精读笔记  关键机制概念笔记
```

在 Better Notes 的创建笔记链接入口中：

- **Link to**：在当前笔记插入所选笔记链接，建立出链。
- **Mention in**：在所选笔记插入当前笔记链接，建立入链。

给每条链接附一句关系理由，例如“展开本文融合模块的计算过程”。正文写出一个论文名，不会自动形成链接；笔记 URL 也不会自动创建 Zotero 子笔记归属或原生 Related 关系。

链接不能编造；`[[论文名]]` 不等于真实 Zotero 笔记关联。

## 适用范围与综述限制

当前版本重点适配遥感、CV、AI 的**方法类论文**，特别是变化检测方向。

综述、理论、数据集、实证和观点文章可以使用共同的原文核对、章节精读、英语答疑和进度规则，但**目前没有分别内置完整的类型专用全文模板和复习卡**。不要将当前版本描述为已经完整兼容所有文章。

阅读综述时可以明确要求：

```text
这是一篇综述。按原始章节精读，重点解释分类体系、技术演进、路线比较和研究空白；不要假定作者提出了新模型或训练 Loss。
```

现有复习卡仍保留固定字段；不适用字段会标注不适用。综述专用分类图谱、系统综述证据评价、理论证明等模板属于后续可扩展范围。

## 阅读记录与恢复

有可写工作目录时，助手维护：

```text
work/paper-reading/<library-id>-<item-key>/record.md
```

无 Zotero 标识时使用可辨认的论文目录名。记录包括论文版本、来源、阅读范围、A/B 模式、章节进度、事实与证据、推断、问题、复习卡修订。

恢复需要该记录可访问；换设备或工作目录时，可把记录一起提供给助手。没有记录时不会假装记得。论文版本更换后需保留旧记录并复核，新版本不能直接继承旧公式和实验结论。

阅读记录属于个人工作数据，不应作为 Skill 通用资源提交到公开仓库。上传时不要包含论文 PDF、个人库标识、私人笔记或本地访问凭据。
