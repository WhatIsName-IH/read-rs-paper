# A：自主通读与逐节精读

初始读取论文建立上下文，不立即系统讲解。告诉用户可以先自行通读、随时答疑。只有用户明确说“读完了”或明确要求现在进入精读时，按论文实际章节顺序开始。每次讲清当前小节，等待用户继续；不一次倾倒整篇。

## A 模式的轻量雅思学习
英文答疑以理解论文为主，每次通常只挑 1–2 个最值得迁移到 IELTS 阅读或写作的要点，如搭配、同义替换、逻辑连接或句型，并简短说明用法。没有明显价值时可省略；用户要求深入英语学习时再展开。不对每个词机械套满模板，不把技术术语、公式或模块解释变成英语课。逐节精读遇到有价值的原文表达时可顺带点出，不另造英语学习任务。

## 答疑格式（A/B 共用）
- **单个普通英文词**：优先英式 IPA、词性（名词注明可数性）与本文含义、1–2 个常见义、2–3 个实用搭配、少量近义表达及差异、本文用法。精简，不罗列词典。
- **短语**：先整体含义，再提取真正值得积累的搭配、结构和替换，避免逐词拆普通词。
- **完整句子**：语境翻译 → 主干与修饰 → 信息组织逻辑 → 少量确有价值的 IELTS/学术表达（A 默认 1–2 个） → 值得迁移时给句型。不要为凑数提取低价值表达。
- **长难句**：增加分层拆句、从主干逐层重组、英文阅读顺序。
- **专业术语**：中文名称 → 概念 → 本文作用 → 实现 → 相关概念区别。即使只有一个词，也优先技术解释，不强套词汇模板。
- **专业追问**：正常展开必要基础知识或研究启发，明确与原文的边界，返回原阅读位置。

词汇收录按 SKILL.md 的“按需收录词汇到 Notion”执行；日常答疑无需套用完整收录模板，用户选词保存时再整理固定五字段。

## Method 深度精读
按原始小节逐节讲解，不机械强套 Backbone/Fusion/Decoder。
每个模块讲清：解决问题、输入与定义、按计算顺序的操作、输出、设计动机、前后模块关系。解释实际运算，不止罗列模块名称。按需给原文张量形状或明确标记的推导。
公式：一句话说明计算目标 → 关键变量、上下标和运算 → 自然语言计算顺序 → 约束与作用 → 必要时最小数值示例。示例明确是教学构造，不是论文设置。公式使用标准 LaTeX 和数学分隔符。
框架图：沿输入到输出追踪，分别解释分支、交互和中间表示，并核对图中文字与正文；按需使用箭头、伪代码或小矩阵，不为展示而机械加示例。
每小节结尾简短总结：解决问题 / 输入 / 核心处理 / 输出 / 作用及证据 / 下一模块。

## 其他章节
Experiments 围绕“实验验证什么、条件和基线、指标含义、结论是否被支持”解释数据集、实现细节、主结果、消融、定性结果与边界。
Conclusion 简洁归纳问题、核心方法、主要实验结论、作者承认的局限与可迁移思想，不重复全文。
用户要求总结 Method 或做笔记时，基于已核对内容按“问题 → 思想 → 数据流 → 模块 → 公式 → 输出 → 创新”压缩，再遵循 better-notes.md。

整篇精读完成或用户明确结束本篇时，执行 SKILL.md 的统一标签与分类收尾；自主通读结束转入精读不算整篇结束。
