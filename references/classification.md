# 阅读结束的分类建议

用户当前的上级分类为“变化识别（Change Detection）”，有效子类别如下。被用户划掉的类别不纳入；未来用户提供新版分类时以新版为准。此表代表用户提供的分类体系，不声称已核实 Zotero 当前状态。

| 已有子类别 | 按核心贡献判断的侧重点 |
| --- | --- |
| 低标注、无监督与样本选择 | 标注效率、弱/半/自监督或无监督学习、主动学习与样本选择 |
| 分辨率适配与影像归一化 | 分辨率差异适配、影像归一化及相关一致性处理 |
| 视觉语言与开放词汇变化检测 | 语言引导、文本提示、开放词汇或开放类别变化检测 |
| 数据集生成与数据增强 | 数据集构建、合成样本及数据增强方法 |
| 网络结构与视觉基础模型 | 网络结构设计、视觉基础模型适配与迁移 |
| 异源影像、配准与成像差异 | 跨传感器/模态差异、几何配准及成像差异处理 |
| 语义变化检测与多模态语言模型 | 语义变化识别，或以多模态语言模型为核心的变化理解 |
| 综述 | 对领域进行系统梳理、比较和总结的综述论文 |

## 选择规则
- 先判断论文真实任务是否属于变化识别，再按核心问题、主要创新与关键实验支持选择最合适的一类，给一句具体理由；备选仅在确实跨类时给出并解释侧重差异，供用户选择。
- 不因用了 Transformer、视觉基础模型或语言模型就归入对应类别。区分作为工具的模型和论文真正贡献，尤其区分开放词汇检测、语义变化检测与语言生成任务。
- “网络结构与视觉基础模型”不是兜底类别。无特别合适的现有类别时明确输出“建议新建：类别名”，说明现有类为何不贴切；必要时说明建议建在当前父类下还是另设父类。
- 非变化识别论文不强行放入该父类，可建议适合的新父类/子类。证据不足时标为“暂定，待核实”，不能以新建类别掩盖尚未理解论文。
- 示例：若变化描述论文的核心贡献是描述生成与评价，现有两类语言相关类别均不贴切，可建议在变化识别下新建“变化描述与文本生成”；若核心贡献实际是多模态语言模型的变化理解，则需结合原文判断已有类别是否合适，不能仅凭任务名称固定新建。
