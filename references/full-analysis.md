# B：直接通读与全文分析

读取全文并建立事实记录后，输出以下五部分。全文不全时注明覆盖范围，不伪称通读。论文非变化检测任务时尊重真实任务，遥感变化检测只作为明确标注的迁移启发。

## 1. 论文做了什么
核心问题与目标、真实输入输出（按需区分 Binary/Semantic Map）、关键贡献、限定比较范围的结果概述。具体数字主要留在实验部分。

## 2. 具体怎么做
先判断技术路线，再沿实际数据流拆解原始模块。仅在适用时使用以下结构：
- Backbone：网络、权重共享、训练/冻结参数、Adapter/LoRA。
- Alignment/Fusion（重点）：两个时相如何形成变化表示，真实运算及分支交互；若声称抑制伪变化，区分设计解释和验证证据。
- Multi-scale/Context：真实多尺度与上下文机制，没有独立模块则明确说明。
- Prediction/Loss：解码与分辨率恢复、预测目标、论文实际损失公式及系数、每项约束。推理型或无训练方法没有 Loss 时写不适用。
模块、公式、框架图的深度规则沿用 guided-reading.md 的 Method 段；无需为 B 加入整篇英语教学。

## 3. 实验与基线
数据集和划分、监督设置、硬件和训练细节（未报告不得猜）、真正比较的基线；呈现必要的 F1/IoU/OA/Precision/Recall 等真实指标。注明单位、对比对象和改善幅度。
解释消融支持哪个结论，不能将不同配置的增益强行排名。区分论文内比较与当前领域最新水平。

## 4. 批判性评价
参数/FLOPs/Latency/资源代价按报告值说明；推导复杂度标明推导。区分作者承认的局限、实验尚未覆盖的条件、分析者提出的风险。不给作者动机定性。

## 5. 研究启发
提供少量具体且有机制依据的切入点，每项含：原方法限制 → 改动 → 假设 → 验证实验与主要风险。避免通用改进清单。

全文分析后默认补一张 Method Memory Card，按 better-notes.md 提供源码；详细报告也可按用户要求转换为源码。
之后继续接受全部追问：单词/句子/术语采用 guided-reading.md 答疑格式，模块与公式按 Method 深度解释；不因已总结而拒绝，不重复全文。追问修正事实时更新记录，并在用户要求时重新生成复习卡。

全文分析与默认复习卡完成后，执行 SKILL.md 的统一标签与分类收尾；B 不额外加入 A 模式的雅思学习环节。
